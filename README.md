# 营销活动用户行为路径分析

一个纯前端、可离线打开的用户行为路径分析报告项目：基于营销活动的用户页面访问日志，对下单与未下单两组用户做前 7 步路径对比，定位转化差异的来源。报告为自包含 HTML（内嵌 SVG 图表与交互脚本），无任何外部依赖。

## 主要内容

| 章节 | 说明 |
|---|---|
| 01 口径与方法 | 用户层 / 访问层 / 结果层三层口径定义 |
| 02 人群规模与漏斗 | 人群口径与行为口径双漏斗 |
| 03 总体路径对比 | 前 7 步桑基图（全量 / 未下单 / 已下单三视图） |
| 04 差异诊断 | 到达率、页面触达、首次跳转、差异分解、深度与时长 |
| 05 转化分析 | 商品级转化漏斗（浏览 × 转化率散点） |
| 06 时间节奏 | 逐日 / 分时 UV 与确认订单率 |
| 07 结论与行动 | 三条结论与产品、运营建议 |

## 报告交互

- **桑基图**：三组视图切换；点击节点可多选并固定，只看所选节点的来向与去向；点击色带追出后续主干路径，双击色带按「到达确认订单概率最高、更早到达」追路径
- **所有图表**：悬停显示数据明细；每张图右上角可下载 SVG
- 逐日 / 分时图支持双轴数值标签

## 使用

### 直接查看报告

用浏览器打开 `output/营销活动用户行为路径分析_脱敏版.html` 即可，无需任何服务。

### 重新生成报告

```bash
cd src
python render.py            # 生成报告（输出路径见脚本顶部 OUT）
python postprocess.py       # 匿名化 HTML 中的页面 ID
python refine.py            # 清理文案与日期
```

生成脚本从 `data/report_data.json` 读取数据，全部为 Python 标准库实现。

### 数据说明

仓库内的 `report_data.json` 已经过两步处理，可直接公开：

1. **脱敏**（`desensitize_data.py` 及发布前处理）：商品名 → 商品A/B/C…，商品 ID → P01…，主要页面 ID → V01…V12，长尾页面 ID → L01…，用户标识与品牌信息移除
2. **模拟化**（`simulate_data.py`）：所有统计量做 ±3% 相对扰动（随机种子固定），分布形状与结论方向保持不变，单个数值不与任何真实数据对应

若需从原始日志重建，参考 `prep.py` 的口径定义自行替换数据源。

## 数据口径

- **UV** = 用户标识 + 访问日期（当次访问）
- **主结果** = 当次访问内是否触达「确认订单页」（同期、可归因）
- 路径窗口为前 10 步，桑基图展示前 7 步
- 「未下单」为观察期用户级标签；两组数据各自独立缩放，跨组比较请使用百分比

## 局限

- 单次观察期数据，不外推其他活动
- 差异为相关性，因果需 A/B 验证
