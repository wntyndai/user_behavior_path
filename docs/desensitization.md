# 脱敏与数据说明

本仓库公开的数据与报告均经过两层处理：

## 1. 脱敏（desensitize_data.py）

| 原内容 | 脱敏后 |
|---|---|
| 商品名称（真实商品名） | 商品A、商品B…（按浏览量降序） |
| 商品 ID（真实编号） | P01–P71 |
| 页面 ID | 主要页面 V01–V12；长尾页面 L01… |
| 用户标识类型 | 泛化为「用户标识」 |
| 品牌 / 活动名 | 移除，统一为「营销活动」 |
| 源表文件名 | 表A / 表B |
| 真实日期 | D01–D41 |

HTML 输出额外经过 `postprocess.py`：桑基图 `data-pid`/`data-s`/`data-t` 等属性中的页面 ID 全部替换（约 3,400 处）。

## 2. 模拟化（simulate_data.py）

随机种子固定（20261110），对所有统计量做 ±3% 相对扰动：

- 顶层规模（UV、用户数）
- 桑基图全部节点占比与边流量
- 商品浏览 / 订单 / 转化
- 到达率、首跳、步数、时长、触达、逐日、逐时
- 差异分解（kitagawa）系数

**保留**：分布形状、大小排序、全部结论方向。
**改变**：每个具体数值不与任何真实数据对应。

## 复现

```bash
cd src
python simulate_data.py    # 重新生成同一批模拟数据
python render.py           # 生成报告
python postprocess.py
python refine.py
```

原始数据与真实 ID 对照表（`_alias_map.json`）不随仓库发布。
